## 🚀 Features
- **Neon cyan + magenta design** (YouTube‑inspired flair)
- **Uploadable cover & profile photos** (saved in your browser via localStorage)
- **5‑page tabbed layout** (Bio, Services, Portfolio, Documents, Contact)
- **Separate HTML documents** for each PDF placeholder (no external PDF hosting needed)
- **Fully responsive** – works on mobile, tablet, and desktop

## 🛠️ How to Deploy on GitHub Pages
1. Fork or clone this repository to your GitHub account.
2. Go to **Settings → Pages**.
3. Under **Branch**, select `main` (or `master`) and save.
4. Your site will be published at:  
   `https://your-username.github.io/victor-malusi-epk/`

## 📸 Customising Images
- Click the **camera icons** on the cover photo and profile picture to upload your own images (they stay saved in your browser).
- Replace the placeholder images in the **Portfolio** gallery by editing the `src` attributes in `index.html` (lines with `work-img`).

## 📄 PDF Documents
The four document links open separate HTML pages. You can replace the content of each `.html` file with your own text or even replace them with actual PDF files (just change the links in `index.html`).
